# Berichtsdefinitionen

Diese JSON-Dateien sind unveränderte Auszüge aus `Report/definition/` der veröffentlichten PBIX. Sie belegen Seiten, Visualtypen und Feldzuordnungen. Sie sind kein vollständiges PBIP-Projekt und werden nicht direkt in Power BI geöffnet. Für die Nutzung die PBIX im Stammverzeichnis verwenden. Der Modellnachweis steht in [MODELL.md](../docs/MODELL.md).
